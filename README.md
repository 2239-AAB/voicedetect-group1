## Calculator web app

A minimal page with two number inputs and a result field.

- **Run it:** open `calculator/index.html` in a browser (no build step, no server needed).
- **Where the math lives:** `calculator/calculation.js`, function `calculate(a, b)`.
  It currently returns `a + b`. To change the operation, edit only that function;
  the UI (`index.html`, `app.js`) calls it and displays whatever it returns.
